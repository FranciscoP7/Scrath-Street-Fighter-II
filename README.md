## 📌 Introdução

Durante o ano de 2022, nas aulas de Tecnologia e Estratégia, recebemos o desafio de criar um jogo usando a plataforma **Scratch**.  
Minha ideia foi desenvolver um jogo simples, mas divertido, aplicando lógica de programação e elementos visuais para criar uma experiência interativa.

## 🎯 Objetivo do Projeto

O principal objetivo era:

- Aprender os fundamentos da programação de forma visual.
- Estimular o pensamento lógico e a criatividade.
- Desenvolver um jogo funcional, com comandos, sprites e interações.
- Entregar um projeto completo, com início, meio e fim.

---

## 🧠 O Que Aprendi

Durante a criação do jogo, aprendi:

- A estruturar comandos e eventos de forma lógica.
- A usar **sprites**, **condições** e **laços** de repetição.
- A testar, corrigir erros e melhorar a jogabilidade.
- Como planejar uma ideia do zero até a execução final.
